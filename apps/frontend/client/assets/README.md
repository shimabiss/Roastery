# 画像アセット

**写真は1枚も置かなくても動きます。** 無ければインライン SVG のイラストが出ます
（`client/images.ts` がビルド時に存在するファイルだけを拾う仕組み）。

置けば写真に差し替わり、消せばイラストに戻ります。

## 手順

### 1. 写真を用意する

必要なのは 5 枚です。**ファイル名は SKU と完全に一致させてください。**

| 置き場所 | 内容 |
|---|---|
| `products/COFFEE-BEANS-1KG.jpg` | コーヒー豆（ホールビーン） |
| `products/MUG-CERAMIC.jpg` | 陶器のマグカップ |
| `products/DRIP-KETTLE.jpg` | 細口のドリップケトル |
| `products/FILTER-100P.jpg` | ペーパーフィルター |
| `hero.jpg` | トップの主役画像（ドリップの様子など） |

拡張子は `.jpg` / `.jpeg` / `.png` のいずれでも構いません。
**横長で、被写体が中央にあるもの**を選んでください（4:3 に中央切り出しします）。

### 2. 変換する

```bash
./scripts/optimize-images.sh
```

WebP 2 サイズ + JPEG フォールバックに変換され、元ファイルは `_original/` へ退避されます。

### 3. 出典を記録する

`CREDITS.md` に記入してください。**Public リポジトリなので、これは省略しないでください。**

### 4. 確認する

```bash
cd apps/frontend && npm run build
```

## ライセンスについて

このリポジトリは **Public** です。同梱する画像は
**再配布可能なライセンスのものだけ**にしてください。

| 調達元 | 商用利用 | 帰属表示 | 注意 |
|---|---|---|---|
| 自分で撮影 | — | 不要 | **最も安全** |
| [Pexels](https://www.pexels.com/license/) | 可 | 任意 | 他のストックサイトへの再配布は不可 |
| Unsplash | 可 | 任意 | 同上。規約は変わることがあるので都度確認 |

> Pexels のライセンスは「他のストック写真・壁紙プラットフォームでの再配布」を
> 禁じています。**コードリポジトリにサイトの素材として同梱するのは
> 通常のサイト利用の範囲**と読めますが、明文化はされていません。
> 気になる場合は自分で撮影した写真を使うのが確実です。

**人物が識別できる写真は避けてください。** 肖像の扱いが別途必要になります。

## なぜ WebP に変換するのか

スマホやストックサイトの写真はそのままだと 2〜6MB あります。
frontend のコンテナイメージにそれが全部乗るため、
**Azure Container Apps の pull 時間とデプロイ時間に直接効きます。**

WebP に落として幅を 2 種類だけ持てば、5 枚合計で数百 KB に収まります。
